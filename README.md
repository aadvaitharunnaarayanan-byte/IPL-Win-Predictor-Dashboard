# IPL-Win-Predictor-Dashboard

PART 1: INTRODUCTION

In T20 cricket, match outcomes can change dramatically within a few overs. Fans, analysts, and teams constantly attempt to estimate the likelihood of victory during a chase, but these assessments are often subjective and influenced by momentum or intuition.

This project uses data analytics to estimate a team's probability of winning at different stages of a run chase by analyzing match context, required scoring rate, wickets in hand, and pressure situations.

The objective is to transform match prediction from opinion-based judgment into a data-driven decision-making process.


PART 2: EXPLANATION

The dashboard evaluates the state of a chase using multiple match context variables.

Key metrics include:
- Current Score
- Target Score
- Runs Required
- Balls Remaining
- Required Run Rate
- Wickets Remaining
- Win Probability
- Pressure Index

The dashboard continuously assesses how these variables interact to influence the chasing team's chances of winning.

Unlike traditional scorecards, this project focuses on the evolving dynamics of a match rather than final results.


PART 3: OUTCOME

The project demonstrates that:
- Match outcomes are highly dependent on evolving game situations.
- Required Run Rate alone is insufficient to assess chase difficulty.
- Wickets remaining play a crucial role in maintaining winning probability.
- Pressure can increase rapidly even when the required run rate appears manageable.
- Small events such as wickets or boundary-heavy overs can significantly alter win probability.

The dashboard successfully converts complex match situations into understandable predictive indicators.


PART 4: CONCLUSION

The IPL Match Winner Predictor provides a dynamic and data-driven framework for evaluating match situations during a chase.

By combining scoring requirements, available resources, and pressure conditions, the project offers a more objective assessment of match outcomes than traditional cricket analysis.

The dashboard highlights how probability and pressure evolve throughout a game, enabling users to understand not only who is likely to win, but also why the match is moving in that direction.
